**System Group** = a collection of various types of systems on a single topic.

For example, a topic may be 'Sleep', and this might have a process for getting ready for bed, a tracker for how many nights in a row you've slept early, some knowledge on circadian rhythms, a music playlist resource for helping to get to sleep, and a mindset for convincing yourself why early nights are so important.

This approach to storing systems means that individual topics can be focused on as needed. If you notice that you want to improve in a specific part of your life, you can observe that system group, and be instantly presented with a linked set of all the systems you need (and **soon** the ability to request new ones if something is missing).
