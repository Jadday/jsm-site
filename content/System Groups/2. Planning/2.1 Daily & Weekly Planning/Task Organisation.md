Task organisation
- Only put in a couple priorities at the start of the day, tag them as so (tempting to arrange everything but it will rarely all get done or stay aligned to timings)
- Pull out more tasks as needed once the priorities are complete

/////

Ensure that daily tasks are prioritised so important things are being done early and optional admin tasks are being done later. If you can do "the frog" in your early morning session, that's perfect.

/////

To beat difficult tasks: make the tasks easy. Anything can seem easy if you break it down enough. Writing the essay becomes doing one section, becomes getting set up at the computer, becomes entering the room. Ticking off tasks feels good, so give yourself these rewards every step of the way.
